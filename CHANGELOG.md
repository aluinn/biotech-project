# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Real screenshots in `docs/assets/` and `npm run screenshots` to regenerate them.
- Zero-dependency local dev server (`npm start`).
- `package.json` with project metadata and Playwright as a dev dependency.
- Community files: LICENSE (MIT), CONTRIBUTING, Code of Conduct, SECURITY,
  ROADMAP, CITATION.cff, EditorConfig, issue and pull request templates, Dependabot.

### Changed

- README rewritten with features, screenshots, FAQ and quick start.

## [0.1.0] - 2026-10-18

### Added

- Search UniProt (reviewed entries, human first) by protein or gene name.
- Interactive 3D viewer for the AlphaFold-predicted structure, coloured by pLDDT.
- Residue inspector on hover (mouse) or tap (touch).
- Five one-click example proteins.
- Responsive light theme with a green accent.
